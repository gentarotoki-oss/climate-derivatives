# 金融工学の概念メモ

## HDD / CDD (Heating / Cooling Degree Days)

- **HDD** = max(T_base - T_avg, 0): 暖房需要の代理変数
- **CDD** = max(T_avg - T_base, 0): 冷房需要の代理変数
- 基準温度 T_base = 65°F (≈ 18.3°C)
- CME先物では月次累積値が取引対象。1 HDD/CDD = $20

## 気候デリバティブの特徴

- 原資産（気温）は取引可能な資産ではない → **不完全市場**
- 株式デリバティブのようなデルタヘッジができない
- プライシングにはリスク中立測度が一意に定まらないため、Market Price of Risk (λ) の仮定が必要

## 主要なプライシング手法

### Burn Analysis
- 過去N年の実績HDD/CDD累積値の統計量から直接価格を推定
- モデルフリー（確率過程の仮定が不要）
- 単純だが、気候変動トレンドへの対応が難しい

### Monte Carlo (OU過程ベース)
- 気温をOU過程でモデリング → リスク中立測度下でパスをシミュレート
- 柔軟性が高いが、パラメータ推定とλの設定が必要
